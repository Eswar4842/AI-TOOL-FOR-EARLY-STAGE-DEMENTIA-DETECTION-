# AI Tool for Early Stage Dementia Detection

Dementia is a progressive neurological disorder that affects memory, thinking, and daily functioning, mainly in older adults. Early detection allows timely medical intervention and better disease management.

This project is an AI-based system that analyzes cognitive assessment data to identify early signs of dementia. Machine learning models use the MMSE score, Functional Assessment score, and Activities of Daily Living (ADL) score to classify individuals as normal, mild cognitive impairment, or early-stage dementia. The system also predicts the probability of dementia and gives supportive explanations to assist healthcare professionals in decision-making.

## Features

- Classifies individuals as normal, mild cognitive impairment, or early-stage dementia
- Predicts the probability of dementia
- Provides supportive explanations based on cognitive analysis results
- Uses simple, easy-to-collect cognitive assessment scores

## Input Parameters

- **MMSE Score**: Mini-Mental State Examination score
- **Functional Assessment Score**: ability to perform functional tasks
- **ADL Score**: Activities of Daily Living score
